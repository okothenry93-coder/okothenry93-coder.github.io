About WATCHIT

A hand-curated movie and music catalog, built and maintained by one administrator.

WATCHIT is a static front-end hosted on GitHub Pages, connected to a Supabase database for its movie and music catalog. There's no recommendation engine and no crowd-sourced content — every title, poster, and audio link is added by hand through the admin dashboard.

Every movie and song points to an external, administrator-provided link rather than a file stored in this repository. WATCHIT never downloads, copies, or re-hosts media — it only links out to sources the administrator has chosen to display.

  • 1administrator, one catalog
  • 0media files stored in this repo
  • 100%external, admin-approved sources
